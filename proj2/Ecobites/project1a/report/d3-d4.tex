\paragraph{Failure explanations (D3).}
\begin{itemize}
\item UC7 detail leak: \texttt{getOrderById} has no ownership check.
\item UC8 late cancel: cancel checks owner only, never status.
\item UC6 payment: \texttt{createOrder} never persists \texttt{paymentMethod}.
\item UC12 stats: aggregates written to \texttt{averageRating}; response reads missing \texttt{restaurantInfo.*}.
\item UC15 combine/\$5: combine does \texttt{rewardPoints += 20}, bypassing mint path.
\item UC15 reward ownership: \texttt{markRewardUsed} ignores caller vs \texttt{userId}.
\item UC17/UC20: no status machine (READY from PLACED; DELIVERED without pickup).
\item UC17 SLA: silent \texttt{PLACED} never auto-cancels.
\end{itemize}
